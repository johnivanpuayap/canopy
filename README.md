# Canopy

> All your projects, one living view.

Canopy is a personal project tracker and idea board for developers. Track your projects' progress, store design docs and specs, and capture ideas on a mood board — all synced across your devices.

## Features

- **Dashboard** — See all active projects with milestone progress at a glance
- **Idea Board** — Mood board-style grid for capturing and browsing ideas visually
- **File Vault** — Store and preview specs, plans, brand docs, and design files
- **Cross-device** — Phone for quick idea capture, laptop for deep work
- **Realtime sync** — Changes appear instantly on all connected devices
- **PWA** — Install on your phone for quick access

## Idea Board

The idea board has two card types:

- **Raw ideas** — Sticky note-style cards for quick capture (title, notes, tags, images)
- **Designed ideas** — Rich brand preview cards showing color palette, typography, tech stack, and tagline (generated by [Crucible](https://github.com/jpuayap/crucible))

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js + Tailwind CSS |
| Backend | Supabase (Auth, Postgres, Realtime, Storage, Edge Functions) |
| Hosting | Vercel |
| Icons | Lucide React |
| Fonts | Outfit + Work Sans |

## Integration with Crucible

Canopy works as a standalone tracker, but pairs with [Crucible](https://github.com/jpuayap/crucible) — a Claude Code skill that generates brand identity, visual design, and tech stack for your ideas. When configured, Crucible automatically pushes generated files to Canopy.
